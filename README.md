# models

Model files for the [Offline AI](https://github.com/newsignlabs/LLM) app, published as assets of the
**models-v1** release by `.github/workflows/publish-models.yml`:

- `qwen3-1.7b-q4_k_m.gguf`: text model (Qwen3 1.7B, Apache-2.0)
- `sd15-q8_0.gguf`: Stable Diffusion 1.5, converted to q8_0 GGUF (CreativeML OpenRAIL-M)
- `lcm-lora-sdv1-5.safetensors`: LCM-LoRA for 4-step images
- `taesd.safetensors`: tiny image decoder (MIT)

Licenses: see `LICENSES.md` in the release. Checksums: `SHA256SUMS` / `manifest.json`.
